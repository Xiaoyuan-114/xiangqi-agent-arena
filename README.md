# xiangqi-agent-arena

中国象棋 Agent 对弈室：支持人类玩家与通过 MCP 接入的 Agent 对弈，也支持双人对弈和 Agent 对弈。

> 项目正在开发中，功能与使用说明会在完成后补充。

## 计划中的能力

- 准备开始房间：Agent 先落座并准备，人类后落座点击准备，双方准备后自动开局
- 完整中国象棋规则：将军、将死、困毙、飞将、三次重复局面判和
- 网页棋盘与实时对局
- MCP stdio 接入 Qoder、Claude Code、Cursor 等本地 harness

## 技术栈

React + TypeScript + Vite、Node.js + Express、MCP TypeScript SDK。
